# 足迹拼图（中国省级版）

选一批旅行照片，按照片里的 GPS 位置自动分到 34 个省级行政区，并把照片拼进省份轮廓里。纯前端，照片不上传，只存在浏览器的 IndexedDB 中。

## 用法

直接用浏览器打开 `index.html` 即可（`china-provinces.js` 需在同目录）。也可以放到任何静态托管（Cloudflare Pages / GitHub Pages）。

- **添加照片（按位置自动分省）**：读取 JPEG 的 EXIF GPS，判断落在哪个省；没有定位的照片进入“待分配”，可手动选省。
- **点省份**：单独添加照片、重排（换一种拼法）、清空、删除单张。
- **多张地图**：可为自己、家人、朋友各建一张。
- **生成分享图**：1500×1500 PNG，长按/右键保存。

## 已知限制

- 只解析 JPEG 的 GPS。HEIC 原图在 Chrome 中无法解码；iPhone 用户从相册选图时系统通常会转成 JPEG，但**是否保留位置信息取决于系统和选择方式**（iOS 选图时可在“选项”里关闭位置）。微信传过的图、截图一般没有 GPS。
- 照片压缩到长边 640px 存储，够拼图用，但不是原图备份。
- 数据只在当前浏览器里，换设备、清缓存都会丢失。
- 省界是低精度数据（约 30 万字节），海岸附近的照片用“0.5° 内最近省份”兜底，极少数边界附近的照片可能分错省。

## 地图合规（公开发布前必读）

省界数据取自 Apache ECharts 4.9.0 内置的 `china.json`（ECharts 5 起已不再内置地图）。这份数据**没有审图号**。按《地图管理条例》，在中国境内公开展示/发布地图（上架应用商店、公开网站）一般需要送审取得审图号，或直接使用自然资源部“标准地图服务”提供的底图。个人自用没问题；如果要公开上线，应先替换为合规底图并核实审图要求。

## 重新生成地图数据

```bash
npm pack echarts@4.9.0 && tar xzf echarts-4.9.0.tgz package/map/json/china.json
python3 tools/build_geo.py package/map/json/china.json china-provinces.js
```
